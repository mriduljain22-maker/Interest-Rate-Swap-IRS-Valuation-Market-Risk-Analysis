# Interest-Rate-Swap-IRS-Valuation-Market-Risk-Analysis
Interest Rate Swap (IRS) Valuation &amp; Market Risk Analysis Using Python

📊 **Project Showcase: Interest Rate Swap (IRS) Valuation & Market Risk Analysis Using Python**

I’m pleased to share a project I developed to apply my financial risk management knowledge to the practical valuation and risk analysis of interest rate swaps.

The objective was to build a Python-based model to understand how changes in market interest rates affect the valuation of an IRS and to measure the associated interest rate risk.

⚙️ **Model Parameters**

* **Notional Principal:** USD 10,000,000
* **Maturity:** 5 years
* **Fixed Interest Rate:** 4.00%
* **Payment Frequency:** Semi-annual
* **Position:** Receive Fixed, Pay Floating

🔍 **Key Components**

* Hypothetical yield curve construction and interpolation
* Discount factor and forward rate calculations
* Fixed-leg and floating-leg present value calculations
* Par swap rate estimation
* DV01 calculation using the central-difference method
* Interest rate stress testing under parallel yield curve shocks
* Automated model consistency checks

💡 **Key Learning**

This project helped me understand how yield curve movements influence swap valuation, how DV01 measures sensitivity to a 1 basis point interest rate change, and how stress testing can help assess potential changes in portfolio value.

🛠️ **Tools Used:** Python | Pandas | NumPy | SciPy | Matplotlib

*Note: This is an educational model based on a hypothetical yield curve and simplified single-curve valuation assumptions. The notional amount is expressed in model currency units.*
